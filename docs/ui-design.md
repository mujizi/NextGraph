# 影谱知识库 UI 细化设计文档

## 1. 产品定位

影谱知识库是一个面向知识库管理、文件解析、AI 图谱抽取、知识库问答和搜索的工作台型应用。整体视觉统一参考最新示例图的浅色蓝灰工作台配色：浅色背景、淡蓝选中态、蓝色功能图标、细分割线和桌面应用式三栏布局，强调清爽、专业、信息密度和可操作性。

核心体验关键词：

- 科技感：浅色冷调底、蓝色高亮、细边框、轻量图标、柔和选中态。
- 工作台：导航清晰、操作入口固定、列表信息密度适中，页面像桌面应用而不是营销站。
- 品牌感：首页明确显示大 Logo，并写明 `欢迎来到影谱知识库`。
- 状态明确：等待、处理中、成功、失败都要可见。
- 知识图谱感：图标、背景纹理和局部视觉元素可体现节点、连接线、文档关系。

## 1.1 参考方向

Home 页面参考图 1：

- 左上角放置大 Logo。Logo 文件由用户提供，前端实现时预留图片位。
- Logo 下方展示欢迎标题：`欢迎来到影谱知识库`。
- 页面上方右侧为胶囊式导航。
- 主体按功能分区展示知识库和聊天入口。
- 卡片风格简洁，使用图标、名称、数量、日期信息。

内部页面参考最新浅色工作台图：

- 采用统一浅色蓝灰科技工作台配色。
- 页面可以有左侧栏、中间主工作区和右侧文件栏。
- 大量使用浅蓝背景、白色面板、细边框、深色文字和蓝色选中态。
- 图标风格模仿图 2 的线性小图标，保持轻、细、克制。

## 2. 全局信息架构

顶部导航栏固定在页面上方，包含 4 个一级入口：

- Home：知识库项目总览。
- 知识库：知识库文件管理、上传、解析、AI 抽取图。
- Chat：选择知识库后进行大模型问答。
- 搜索：跨知识库或指定知识库搜索。

页面路由建议：

- `/` 或 `/home`：Home 页面。
- `/knowledge`：知识库入口页。
- `/knowledge/:projectId`：知识库详情页。
- `/chat`：Chat 知识库选择页。
- `/chat/:projectId`：知识库对话页。
- `/search`：搜索页。

## 3. 全局布局

### 3.1 顶部栏

顶部栏高度建议 56px 到 64px。Home 页面可采用图 1 的右上胶囊导航；进入功能页面后使用更接近图 2 的桌面应用顶部栏。

左侧：

- Home 页面：左上显示用户提供的 Logo 图片，建议尺寸 40px 到 56px，可根据图片比例自适应。
- 功能页面：显示小尺寸 Logo + 当前知识库或页面名称。

中间：

- Home
- 知识库
- Chat
- 搜索

右侧：

- 全局搜索入口或快捷搜索图标。
- 用户头像/用户名。
- 系统状态或通知入口，可选。

导航状态：

- 默认：深蓝灰文字。
- Hover：淡蓝背景，文字变为品牌蓝。
- Active：浅蓝底或白色胶囊底，边缘带品牌蓝细描边。

## 4. Home 页面

### 4.1 页面目标

Home 是用户进入系统后的主页面，用于欢迎用户、快速查看最近知识库项目、快速进入聊天，并创建新的知识库项目。

### 4.2 页面结构

首屏顶部区域：

- 左上角：大 Logo 图片位。
- 右上角：胶囊导航，包含 Home、知识库、聊天、搜索。
- 标题：`欢迎来到影谱知识库`
- 标题中的品牌名可使用蓝到青的渐变文字。
- 标题下方可显示简短统计，例如 `管理知识库、解析文件、抽取图谱并开始智能问答`。
- 右侧或标题下方主按钮：`新建知识库项目`

主内容区域：

- 分成 `知识库` 与 `聊天` 两个区域，布局参考图 1。
- 每个区域左侧有线性图标和标题。
- 知识库项目以「文件夹/知识库图标」卡片网格展示。
- 每个项目卡片呈现不同的文件夹样式或知识库样式图标。
- 卡片包含名称、创建日期、创建人、文件数量或解析状态摘要。
- 每个区域最后一个卡片可为 `查看全部 >`，点击进入对应完整列表。

### 4.3 项目卡片设计

卡片尺寸建议：

- 桌面端：每行 3 到 4 个。
- 平板端：每行 2 个。
- 移动端：每行 1 个。

卡片内容：

- 左上：项目图标，使用文件夹、书本、节点图谱等差异化图标。
- 右上：更多操作按钮。
- 主标题：知识库名称。
- 元信息：
  - 创建日期：`2026-04-27`
  - 创建人：`Mengna`
  - 文件数量：`128 files`
- 底部状态：
  - `已解析`
  - `待解析`
  - `部分失败`

视觉建议：

- Home 卡片背景使用 `#FFFFFF` 或 `#F8FBFF`，边框使用 `#D7E3F4`。
- 选中或 hover 卡片使用 `#E8F1FF` 淡蓝背景。
- Hover 时边框变为品牌蓝，卡片轻微上浮，图标产生轻微发光。
- 图标可模仿参考图的方形字母图标：使用知识库名称首字母，配绿色、蓝色、青色渐变底。
- 点击卡片进入知识库详情页。

### 4.4 新建知识库项目

点击 `新建知识库项目` 后打开弹窗。

弹窗字段：

- 知识库名称，必填。
- 描述，可选。
- 创建人，默认当前用户。
- 知识库类型，可选：
  - 通用知识库
  - 文档知识库
  - 项目知识库
  - 图谱知识库

弹窗操作：

- 取消
- 创建

创建成功后：

- 回到 Home。
- 新项目卡片出现在列表第一位。
- 卡片状态为 `空知识库` 或 `等待上传`。

## 5. 知识库页面

知识库页面包含两种状态：入口选择页和详情管理页。

### 5.1 知识库入口页

如果用户不是从 Home 的某个项目直接进入，而是点击顶部导航 `知识库`，则展示知识库选择页。

布局与 Home 的项目网格相似：

- 标题：`知识库`
- 说明：选择一个知识库开始管理文件。
- 项目卡片：与 Home 一致，但更强调文件数量、解析进度和最近处理状态。

点击某个卡片后进入该知识库详情页。

### 5.2 知识库详情页

页面目标：

- 展示当前知识库中的文件列表，布局参考示例图的浅色蓝灰工作台表格页。
- 支持上传文件和上传文件夹。
- 支持勾选文件后解析。
- 支持解析完成后进行 AI 抽取图。
- 展示每个任务的等待、处理中、成功、失败状态。

### 5.3 页面头部

左侧：

- 页面标题：`文件列表`
- 标题下方说明：`解析成功后才能问答哦。`
- 如果需要展示当前知识库名称，可放在标题右侧的小标签中，例如 `影谱项目库`。

右侧：

- 图标按钮：AI 抽取图，使用 MagicWand / Sparkles 图标。
- 图标按钮：筛选，使用 Funnel 图标。
- 搜索框：placeholder 为 `搜索`。
- 主按钮：`+ 新增文件`。
- 次按钮或下拉项：`新增文件夹`。

按钮建议使用图标加文字：

- 上传文件：Upload 图标。
- 上传文件夹：FolderUp 图标。
- AI 抽取图：Sparkles 图标。
- 筛选：Funnel 图标。

### 5.4 文件列表

文件列表采用横向浅色表格。

浅色表格推荐配色：

- 页面背景：`#F6F9FF`
- 表头背景：`#F1F6FD`
- 表格行背景：`#FFFFFF`
- 表格 hover：`#F3F7FF`
- 表格边框：`#D7E3F4`
- 主文字：`#172033`
- 次级文字：`#66758F`
- 启用开关：开启为蓝色 `#3F7BFF`

列建议：

- 选择框
- 文件名
- 上传时间
- 启用
- 分块数
- 元数据
- 解析
- 操作

文件名区域：

- 根据文件类型展示图标，如 PDF、DOCX、TXT、MD、CSV。
- PDF 图标可使用红色小文件标识，贴近参考图。
- 文件名超长时单行省略。

表格列细节：

- `选择框`：表头支持全选，单行支持勾选。
- `文件名`：显示文件类型图标 + 文件名。
- `上传时间`：格式为 `21/04/2026 09:59:20`，与参考图一致。
- `启用`：使用开关控件；关闭后文件不参与 Chat 索引和搜索召回。
- `分块数`：显示解析后的 chunk 数，例如 `1354`。
- `元数据`：显示字段数量，例如 `0 fields`，点击可打开元数据编辑面板。
- `解析`：显示解析策略或解析结果，例如 `Book`、`PDF`、`Text`、`Markdown`。
- `操作`：放置进度/重试/更多操作图标。

状态展示：

- 等待中：灰色圆点或灰色时钟图标 + `等待中`
- 处理中：青色旋转图标 + 行内细进度条
- 成功：绿色圆点或 Check 图标 + `完成`
- 失败：红色 X 图标 + `失败` + 错误提示入口

### 5.4.2 顶部工具按钮规则

- `+ 新增文件`：主操作，点击打开文件上传。
- `新增文件夹`：可作为 `+ 新增文件` 的下拉项，也可独立显示为次按钮。
- `搜索`：只过滤当前知识库文件列表，不跳转全局搜索页。
- `筛选`：支持文件类型、启用状态、解析状态、上传时间。
- `AI 抽取图`：默认可见；未选择文件时置灰，已选择且解析完成后可点击。

### 5.5 批量操作区

当用户勾选文件时，文件列表上方出现批量操作栏。

内容：

- 已选择数量，例如：`已选择 8 个文件`
- 全选/取消全选
- `解析文件`
- `AI 抽取图`
- `启用`
- `停用`
- `删除`

规则：

- `解析文件`：选中文件即可点击。
- `AI 抽取图`：只有选中文件中存在已解析成功的文件时才可点击。
- 如果全部选中文件都未解析完成，则 `AI 抽取图` 置灰，并显示 tooltip：`请先解析文件`。

### 5.6 上传后的操作流程

上传文件或文件夹后，文件进入列表，默认状态：

- 解析状态：`等待中`
- AI 抽取图状态：`等待中`

用户可以：

1. 勾选一个或多个文件。
2. 点击 `解析文件`。
3. 文件进入 `处理中`，显示进度条。
4. 解析完成后状态变为绿色 `完成`。
5. 解析失败则状态变为红色 `失败`，操作列提供 `重试`。
6. 对解析完成的文件点击 `AI 抽取图`。
7. 抽取图任务进入 `处理中`，显示独立进度条。
8. 完成后状态变为绿色，可提供 `查看图谱` 操作。

### 5.7 进度条状态

处理中：

- 蓝色进度条。
- 显示百分比。
- 可选显示当前阶段，例如 `文本解析中`、`向量化中`、`图谱抽取中`。

等待中：

- 不显示进度条或显示灰色空进度条。
- 文案：`等待中`。

成功：

- 进度条满格，绿色。
- 文案：`完成`。

失败：

- 红色短进度条或红色状态条。
- 文案：`失败`。
- Hover 或点击可查看失败原因。

## 6. Chat 页面

Chat 页面参考最新浅色工作台图，配色不单独改动，统一使用浅色蓝灰体系：浅蓝灰背景、白色面板、细边框、深色文字、蓝色选中态。

### 6.1 Chat 知识库选择页

如果用户直接点击顶部导航 `Chat`，先展示知识库选择页。

布局类似 Home：

- 标题：`Chat`
- 副标题：选择一个知识库开始问答。
- 知识库卡片：显示名称、文件数量、解析完成数量、最近更新时间。

点击某个知识库后进入聊天页。

### 6.2 聊天详情页

页面目标：

- 基于选中的知识库与大模型对话。
- 系统自动索引知识库相关内容并生成回答。
- 回答中展示引用来源或命中文件。

### 6.3 聊天页面布局

整体布局：

- 左上角保留 Logo。
- 右上角使用与 Home 一致的胶囊导航，包含 Home、知识库、聊天。
- 当前 `聊天` 导航项为选中态，浅蓝底或白色胶囊底配蓝色描边。
- 页面主体分为左侧会话栏和中间聊天主区域。
- 左侧会话栏宽度约 292px，中间主区域占据剩余宽度。
- 两个区域之间使用浅蓝细边框分割。

左侧侧栏：

- 顶部显示当前知识库入口：方形首字母图标 + 知识库名称，例如 `test2`。
- 知识库名称右侧有发送/进入图标，可用于切换或进入知识库。
- 侧栏可折叠，折叠按钮放在靠右边缘。
- 会话标题：`会话 7`。
- 标题右侧有 `+` 新建会话按钮。
- 标题右侧可有删除/清理会话图标。
- 会话搜索框 placeholder 为 `搜索`。
- 会话列表显示历史问题，超长单行省略，例如 `一个真正有力量的主角，...`。
- 当前会话可使用略亮背景或文字高亮。

中间主区域：

- 顶部栏显示当前会话名，例如 `新会话`。
- 顶部栏下方是消息流区域。
- 用户消息靠右。
- AI 消息靠左。
- AI 回答下方展示引用来源。
- 空会话时主区域保持留白，不放复杂引导文案。

底部输入区：

- 固定在主区域底部。
- 多行输入框 placeholder 为 `请输入消息...`。
- 左下角有附件/引用按钮。
- 输入框底部有 `Thinking` 模式按钮。
- 右下角有发送按钮。
- 输入框外框使用细边框，背景为白色面板。

### 6.4 AI 回答状态

等待：

- 输入框上方或消息区显示 `正在检索知识库...`

生成中：

- 显示流式输出。
- AI 消息旁显示动态状态点。

完成：

- 展示完整回答。
- 展示引用文件，例如 `来源：产品需求.md、接口文档.pdf`。

失败：

- 显示错误状态。
- 提供 `重试` 按钮。

## 9. 状态模型

### 9.1 文件状态

文件解析状态：

- `idle`：等待中
- `processing`：处理中
- `success`：完成
- `failed`：失败

AI 抽取图状态：

- `disabled`：不可操作，文件尚未解析完成
- `idle`：等待中
- `processing`：处理中
- `success`：完成
- `failed`：失败

### 9.2 状态颜色

- 等待中：灰色
- 处理中：蓝色
- 成功：绿色
- 失败：红色
- 不可用：低透明灰色

## 10. 交互细节

### 10.1 选择与批量处理

- 表头提供全选 checkbox。
- 单个文件提供 checkbox。
- 勾选后显示批量操作栏。
- 批量操作栏应固定在文件列表上方，避免滚动丢失。

### 10.2 禁用规则

- 未选择文件时，`解析文件` 和 `AI 抽取图` 不显示或置灰。
- 文件解析中时，不允许重复点击 `解析文件`。
- 文件未解析成功时，不允许执行 `AI 抽取图`。
- 任务处理中时，上传按钮仍可用，但同一文件的处理操作禁用。

### 10.3 反馈方式

- 上传成功：右上角 toast。
- 解析开始：文件状态立即变为处理中。
- 解析完成：状态变绿，并 toast 提示。
- 失败：状态变红，显示重试入口。

## 11. 科技感视觉规范

### 11.1 背景

Home、知识库文件页、Chat 页和搜索页统一使用最新示例图的浅色蓝灰科技风，不再切换深色主题。

Home 背景建议：

- 主背景为浅蓝灰 `#F6F9FF`。
- 内容区不铺满卡片，保留大面积留白。
- 卡片使用白色或极浅蓝面板和细边框，营造克制的科技感。
- 欢迎标题中 `影谱知识库` 可使用蓝色渐变文字。

功能页背景建议：

- 采用浅蓝灰背景。
- 左侧栏、主内容区、右侧文件栏用浅蓝细线分隔。
- 选中项使用淡蓝底，类似示例图中的会话选中态。
- 输入框、文件树、表格使用白色或极浅蓝面板。
- 可使用非常克制的数据网格纹理，但透明度要低。
- 不使用大面积渐变球或装饰性光斑。

### 11.2 图标

图标风格统一为线性小图标，模仿参考图 2 的轻量工具栏风格。Home 卡片中的项目图标可模仿参考图 1 的彩色方块字母图标。

建议图标：

- Home：Home
- 知识库：BookOpen
- Chat：MessageSquare
- 搜索：Search
- 上传文件：Upload
- 上传文件夹：FolderUp
- 文件夹：Folder
- 知识库项目：Library / Database
- 处理中：Loader
- 完成：CheckCircle
- 失败：XCircle

图标细节：

- 顶部导航图标尺寸 18px 到 20px。
- 侧栏图标尺寸 18px。
- 文件列表图标尺寸 16px 到 18px。
- Home 卡片首字母图标尺寸 32px 到 36px。
- 线性图标描边建议 1.75px 到 2px。

### 11.3 动效

动效保持轻量：

- 卡片 hover：边框变亮，轻微上浮 2px。
- 处理中：进度条流动。
- 导航 active：底部高亮线。
- 弹窗：淡入和轻微缩放。

动画时长建议 120ms 到 220ms。

### 11.4 应用框架质感

功能页增加桌面应用质感：

- 顶部保留细边框分割线。
- 左侧栏宽度建议 280px 到 320px。
- 右侧文件栏宽度建议 300px 到 360px。
- 中间主工作区自适应。
- 文件树、会话列表、知识库列表都使用统一的淡蓝选中背景和蓝色图标样式。

## 12. 空状态

Home 无知识库：

- 保留左上 Logo 和欢迎标题。
- 知识库区显示书本/文件夹组合图标。
- 文案：`还没有知识库项目`
- 主按钮：`新建知识库项目`

知识库无文件：

- 显示上传图标。
- 文案：`上传文件或文件夹开始构建知识库`
- 操作：`上传文件`、`上传文件夹`

搜索页空状态：

## 13. 页面流程

### 13.1 创建并处理知识库

1. 用户进入 Home。
2. 点击 `新建知识库项目`。
3. 创建成功后进入项目卡片列表。
4. 点击项目卡片进入知识库详情。
5. 上传文件或文件夹。
6. 勾选文件。
7. 点击 `解析文件`。
8. 解析完成后点击 `AI 抽取图`。
9. 完成后可进入 Chat 或搜索页面使用知识库。

### 13.2 知识库聊天

1. 用户点击顶部导航 `Chat`。
2. 选择一个知识库。
3. 进入聊天页面。
4. 用户输入问题。
5. 系统检索知识库内容。
6. 大模型生成回答。
7. 回答展示引用来源。

### 13.3 搜索

1. 用户点击顶部导航 `搜索`。
2. 输入关键词。
3. 按 Enter 或点击搜索图标触发搜索。

## 15. 验收标准

- 顶部导航包含 Home、知识库、Chat、搜索，并能清晰显示当前页面。
- Home 页面能看到多个不同样式的知识库项目卡片。
- 用户能创建新的知识库项目。
- 从 Home 点击项目能进入知识库详情页。
- 从顶部 `知识库` 直接进入时，先展示知识库选择页。
- 知识库详情页以文件列表展示文件。
- 文件列表页顶部显示 `文件列表` 和 `解析成功后才能问答哦。`。
- 右上角有 AI 抽取图、筛选、搜索、`+ 新增文件` 操作。
- 新增文件可支持上传文件，上传文件夹可作为下拉项或次按钮。
- 文件表格包含名称、上传日期、启用、分块数、元数据、解析、动作列。
- 启用列使用开关控件。
- 分块数显示解析后的 chunk 数量。
- 元数据列显示字段数量，例如 `0 fields`。
- 上传后文件进入等待中状态。
- 用户可勾选文件、全选文件。
- 点击解析文件后显示进度条。
- 解析成功变绿，失败变红。
- AI 抽取图按钮只有在解析完成后可用。
- Chat 页面直接进入时先选择知识库。
- Chat 详情页支持基于知识库的问答布局。
- 搜索页面只显示一个搜索框，并支持输入关键词触发搜索。
